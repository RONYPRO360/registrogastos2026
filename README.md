# Registro de Gastos

Aplicación de consola desarrollada en C# (.NET) para gestionar gastos personales con persistencia en archivos CSV.

## Cómo ejecutar el proyecto

1. **Abrir el proyecto:** 
   Abre Visual Studio y selecciona el archivo de solución `registrogastos.slnx`.

2. *Compilar y correr
   Presiona la tecla F5 (o Ctrl + F5) para ejecutar la consola de comandos.

3. **Uso de la aplicación:**
   Al iniciar, el programa cargará automáticamente tus registros previos si existe el archivo `gastos.csv`. Usa el menú interactivo para:
   - **Opción 1:** Registrar un nuevo gasto ingresando descripción, monto y categoría.
   - **Opción 2:** Ver el listado completo de gastos anotados y el monto total acumulado.
   - **Opción 3:** Filtrar y buscar gastos según su categoría.
   - **Opción 4:** Guardar los datos automáticamente en el CSV y salir del programa.
